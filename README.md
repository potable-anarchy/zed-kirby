# Kirby Theme for Zed Editor

A dreamy pink theme for Zed inspired by Nintendo's beloved Kirby character from HAL Laboratory.

## Installation

1. Clone this repository or download the theme file
2. Copy `themes/kirby.json` to your Zed themes directory:
   - **macOS/Linux**: `~/.config/zed/themes/`
   - **Windows**: `%APPDATA%\Zed\themes\`
3. Open Zed and select the theme:
   - Open Command Palette (Cmd/Ctrl + Shift + P)
   - Type "theme selector" and press Enter
   - Choose "Kirby" or "Kirby Light"

## Theme Variants

- **Kirby** - Dark theme with soft pink and purple tones
- **Kirby Light** - Light theme with pastel pink accents

## Color Palette

The theme uses Kirby's signature pink color palette:
- Primary Pink: `#d74894`
- Soft Pink: `#df6da9`
- Light Pink: `#e791bf`
- Pastel Pink: `#efb6d4`
- Very Light Pink: `#f7daea`

## Features

- Carefully crafted syntax highlighting
- Both dark and light variants
- Soft, eye-friendly colors
- Kirby-inspired pink and purple palette
- Consistent UI theming throughout Zed
